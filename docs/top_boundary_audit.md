# Top boundary

The current open top supplies the reference atmosphere as the external HLL
state. It is not a full characteristic radiation condition. The sponge begins
at 75% of the domain height with rate [(z-z_start)/(z_top-z_start)]² / 100 s.
For the 450 km control this means 337.5–450 km; the local damping time is
100 s at the top face and longer below it. The frozen running ERA5 refinement
was not modified.

`src/bin/test_top_absorption.rs` measures returned normal acoustic characteristics
in a uniform 300 K, zero-gravity radial pulse on the actual spherical finite-volume
operator. Top 300 km, 2 km layers, pulse centre 100 km and Gaussian sigma 8 km;
probe 179 km. Outgoing/incoming pressure characteristics are
(p' ± rho*c*w)/2. The diagnostic compares squared incoming signal integrated
from 500–1400 s with outgoing signal integrated from 0–450 s. Geometric spreading,
numerical attenuation and finite measurement windows affect this ratio.

Returned characteristic energy ratios:
- reflecting lid: 0.88016456
- reflecting lid plus sponge: 0.04244810
- open top: 0.00002754568
- open top plus sponge: 0.00001774873

Evidence `data/top_absorption_audit.h5`; figure generated by
`scripts/plot_top_absorption.py`. This establishes good absorption for this weak
normal acoustic pulse, not for oblique internal gravity waves, a strongly
stratified profile or all wavelengths. An upward phase slope alone does not
identify a reflected wave. Before strengthening the sponge or changing the
boundary, measure incident/returned packets and vertical pressure-work flux in
a resolved stratified wave test. A sponge can itself reflect if its damping
changes too sharply.

Run:
`conda run -n base sh -c 'HDF5_DIR="$CONDA_PREFIX" cargo run --release --bin test_top_absorption -- data/top_absorption_audit.h5'`
